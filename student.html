About This Project

A simple academic record management application built with front-end web technologies.

🎯

Project Purpose

This project helps organize student information in one place. It makes adding, viewing, updating, deleting, and finding student records easier.

⚙️

Key Features

  • Add new student records
  • View all student details
  • Edit existing information
  • Delete records with confirmation
  • Search and filter students
  • Save data in browser storage
💻

Technology Stack

  • HTML — page structure
  • CSS — styling and animations
  • JavaScript — CRUD operations
  • DOM — dynamic table updates
  • localStorage — browser data storage
  • Responsive layout for small screens
